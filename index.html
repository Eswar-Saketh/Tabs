Lesson 02

Selecting Elements

You need a reference to a node before you can change it. These three lookups cover almost every case.

getElementById()

Finds one element by its unique id. Direct when you already know that id.

document.getElementById("panel-1")

querySelector()

Finds the first element that matches a CSS selector.

document.querySelector(".tab")

querySelectorAll()

Finds every match and returns a list you can loop over.

document.querySelectorAll(".tab")

Lesson 04

Updating the DOM

Once you have an element, these four tools change what it shows.

textContent

Replaces the text inside an element. Use it for plain text.

innerHTML

Replaces markup. Only use HTML you trust, never raw user input.

classList

Adds, removes, or toggles classes. This is the usual way to restyle.

style

Sets one inline style, such as color. Prefer a class when the look is reused.
